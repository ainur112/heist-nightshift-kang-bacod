A keyboard-and-mouse stealth heist that runs entirely offline in the browser. Sneak through three floors — ATRIUM, SERVER GALLERY and TOP FLOOR VAULT — using cover, timed camera arcs, distraction lures, a micro EMP and a phase cloak. Take the VAULT CORE on each floor and reach EXFIL before the alarm hits 100%.

## Run

```
node serve.ts
```

Open http://127.0.0.1:8080/ — no build step, no dependencies, no network at runtime.

Controls: WASD / arrows to move, Shift to sprint, E to take the core / hack a terminal / extract, 1–3 to select a gadget and click to deploy, R to restart.
